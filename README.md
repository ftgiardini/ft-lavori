# FT Giardini · Lavori

App per organizzare i lavori nei condomini sotto contratto di FT Giardini: calendario degli interventi, spunta dei lavori fatti, squadra, preventivi in PDF.

- Funziona dal browser e si installa sulla schermata Home dell'iPhone (PWA).
- Dati condivisi e accessi con password tramite Supabase (`js/config.js`, `supabase/`).
- Nessun passaggio di compilazione: sono file statici pubblicati con GitHub Pages.

Guida completa per la messa online: [GUIDA-ONLINE.md](GUIDA-ONLINE.md).
